# Rastreador de trabalho: Markdown local

Enquanto este repositório não tiver um remoto ou rastreador configurado, especificações e tarefas ficam em `.scratch/<tema>/`.

- A especificação de um tema fica em `.scratch/<tema>/spec.md`.
- Tarefas de implementação, quando criadas, ficam em `.scratch/<tema>/issues/NN-descricao.md`.
- A linha `Status:` no início de cada arquivo registra o estado de triagem.
- Esta convenção pode ser migrada para um rastreador remoto quando um for configurado.
